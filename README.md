# Sales Data Analysis

**CodeNova Data Science Internship — Task 1**

## 1. Project Overview

This project focuses on analyzing the Sample Superstore sales dataset using Python. The analysis explores sales revenue, profit, product categories, regional performance, and sales trends over time.

The main goal is to understand the dataset, calculate important business metrics, and present the results through charts and summary tables.

## 2. Project Objectives

- Calculate total sales, total profit, profit margin, average order value, and units sold.
- Analyze monthly and quarterly sales trends.
- Compare sales and profitability across product categories.
- Identify top-performing products.
- Examine sales performance across regions and states.
- Summarize the results using charts and CSV reports.

## 3. Dataset

**Dataset:** `Sample - Superstore.csv`

The dataset contains order, product, sales, profit, quantity, customer segment, and geographic information.

Important columns include:

| Column | Purpose |
|---|---|
| Order ID | Count unique orders |
| Order Date | Analyze sales trends |
| Sales | Calculate revenue |
| Profit | Measure profitability |
| Quantity | Calculate units sold |
| Category | Compare product categories |
| Product Name | Analyze product performance |
| Region | Compare regional sales |
| State | Examine state-level sales |
| Segment | Compare customer segments |

The dataset is stored in the `data/` directory.

### Metric Calculations

- **Total Sales:** Sum of all values in the Sales column.
- **Total Profit:** Sum of all values in the Profit column.
- **Profit Margin:** Total Profit / Total Sales × 100.
- **Average Order Value:** Total Sales / Number of unique orders.
- **Total Units Sold:** Sum of the Quantity column.
- **Unique Orders:** Count of distinct Order IDs.

## 10. How to Run the Project

### Requirements

Python 3 and the required Python libraries must be installed.

Install the libraries using:

```bash
python -m pip install pandas numpy matplotlib seaborn jupyter
```

### Run the Python Script

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Confirm that `data/Sample - Superstore.csv` exists.
4. Open a terminal in the project directory.
5. Run:

```bash
python sales_analysis.py
```

The script reads the dataset and saves its charts and summary reports in the `outputs/` directory.

### Run the Notebook

Open `Sales_Data_Analysis.ipynb` in Jupyter Notebook or Visual Studio Code and execute the cells in order.
